# Budget

## 개요
구글 스프레드시트 기반 가계부를 단계적으로 디벨럽하는 프로젝트.

- **1단계**: 스프레드시트 구조 개선
- **2단계**: 앱/웹 서비스 개발 (플랫폼 미정)

## 시트 구조

### 1. `financial-plan` (2026 시트)
> 연간 가계설계 — 수입 계획, 카테고리별 예산 목표 설정

- **앱에서의 역할**: 계획(Target) 레이어
- **핵심 데이터 모델**: `Budget` / `Plan`
- 유저가 한 해의 재정 목표를 설계하는 시트

---

### 2. `expense-log` (2026 생활비 시트, gid=775397077)
> 실제 지출내역서 — 일별 트랜잭션 기록

- **앱에서의 역할**: 실적(Actual) 레이어
- **핵심 데이터 모델**: `Transaction` / `Expense`
- 실제 소비를 날짜별로 기록하는 시트

#### 현재 컬럼 구조
```
| 날짜 | 항목 | 금액 |
```

## 두 시트의 관계 (앱 설계 관점)

```
financial-plan  →  "이번 달 식비 예산 ₩300,000"   (계획)
expense-log     →  "실제 식비 지출 ₩342,000"       (실적)
                                        ↓
                         예산 대비 초과 ₩42,000 표시  (분석)
```

---

## 현재 한계점 (개선 필요)

1. **카테고리 없음** — 식비/육아비/교통비 등 분류 불가
2. **수입 내역 없음** — 지출만 기록, 수입 흐름 파악 안 됨
3. **가로 레이아웃** — 필터링/분석 불편
4. **결제 수단 없음** — 카드/현금 구분 없음
5. **메모 없음** — 항목 부연 설명 불가
