# 사용 시나리오 — 설정

> (Claude 초안 — 홈 화면 하단 네비 "설정" 진입. 스프레드시트 `설정` 탭(①가구원 수 ②가구원 이름/색상) + 온보딩에서 입력한 소득·고정비·목표 비율을 재설정하는 화면)

## 1. 가구원 관리

- 설정 탭 구조 그대로: 가구원 수(1~5명) + 가구원별 이름/색상
- 가구원 수를 늘리면 새 가구원 이름 입력 필드가 나타남(온보딩 "가구원 등록"과 동일 입력 방식)
- 가구원 수를 줄이면 해당 가구원의 과거 지출 기록은 유지하되(삭제하지 않음), 태깅 목록에서만 제외
- 색상 변경: 가구원별 태그 색상 선택 (Apps Script A-2 자동 동기화 대상과 동일한 값)
- **소득관리 대상(처음 2명) 변경 불가** — 온보딩에서 등록 순서로 고정된 정책이라, 순서를 바꾸려면 가구원을 삭제 후 재등록해야 함을 안내 문구로 표시

## 2. 소득 재설정

- 온보딩 "소득 입력"과 동일한 화면 재사용 (가구원1/가구원2 월 평균 소득)
- 수정 시 하단에 "여유예산이 [기존 X]원 → [변경 후 Y]원으로 바뀌어요. 3번(목표)에서 각 항목 비율을 다시 확인해주세요" 안내

## 3. 고정비 재설정

- 온보딩 "고정비/주거", "고정비/보험"과 동일한 화면 재사용
- 항목: 대출금, 주거 관리비, 통신비, 재산세(월 환산), 보험비(가구원별 월 평균)
- 홈 화면 상단 요약에 "고정비는 변경 없으면 매달 자동 동일 차감"이라 명시돼 있으므로, 여기서 값을 바꾸면 **바꾼 시점 이후 달부터** 새 금액 적용 (과거 달 기록은 소급 변경 안 함)

## 4. 목표 재설정 (생활비/저축/노후자금/비상금/용돈)

- 온보딩 "희망고문" 이후 5개 세팅 화면과 동일한 슬라이더/입력 재사용
- 여유예산(=소득−고정비) 기준 4:4:2:1:1 제안 비율을 다시 보여주되, 사용자가 직접 조정한 현재 값이 기본으로 채워짐
- **하나만 수정 시 자동 재배분**: 특정 항목 비율을 바꾸면 나머지 4개 항목이 기존 비율(예: 저축:노후자금:비상금:용돈 = 4:2:1:1)을 유지한 채 비례 축소/확대되어 합계가 항상 자동으로 100%를 맞춤 — 온보딩 최초 설정과 동일한 로직
- 용돈은 가구원1·2 배분 비율(소득 비례 기본값)도 여기서 재조정 가능

## 5. 알림 설정

- 온보딩에는 포함하지 않음 — 설정 화면에만 존재하며 기본값 ON으로 켜진 상태로 시작 (초기 세팅 흐름을 방해하지 않기 위함)
- 이번 달 목표 초과 경고 알림 on/off (소비형 카테고리: 생활비/용돈/비상금)
- 저축·노후자금 이체 미완료 알림 on/off (월말 임박 시)
- 알림 시점: 즉시(지출 입력 시) vs 일 1회 요약 중 선택

## 6. 데이터·동기화

- 앱→스프레드시트 월간 싱크 상태 표시: "마지막 동기화: [날짜]" (B-1 구현 후)
- 수동 "지금 동기화" 버튼 (선택)
- 계정 정보, 로그아웃
