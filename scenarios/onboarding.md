# 사용 시나리오 — 온보딩 (초기 세팅)

가구원 중 1명이 세팅 시작.

## 프롤로그

1. 안녕하세요! 버짓 앱입니다. 버짓앱은 '~한' 서비스예요
2. 버짓앱을 사용하기 위해서는 다음과 같은 초기 정보가 있을 때 빈틈없는 가계운영이 가능해요!
   - 주거비: 대출금 / 주거 관리비 / 통신비 / 재산세를 대략적으로 산정해서 입력해주세요.
   - 보험비: 월 평균 보험비를 대략적으로 입력해 주세요.
   지금 입력하지 않아도, 추후 입력으로 가계 세팅이 가능합니다. (하지만 좀더 정교한 세팅이 가능해요)
3. 자 그럼, 시작해 볼까요?

## 가구원 등록

> (가구원은 소비 태깅용으로 최대 5명까지 등록 가능. 단 소득/예산 관리는 **등록 순서상 처음 2명**으로 제한 — 아래 "소득 입력" 참고. 스프레드시트 `설정` 탭 구조를 그대로 따름, 별도 스키마 변경 없음)

1. 버짓앱은 가족 단위로 예산을 관리해요! 먼저 몇 분이 함께 가계부를 쓰실지 알려주세요.
2. 몇 명이 함께 사나요? (1~5명)
3. 각 가구원의 이름(또는 별명)을 입력해주세요. (예: 지원, 윤혜, 아이)
4. 좋아요! 가족 구성이 등록됐어요.

## 소득 입력

> (이 값이 있어야 아래 생활비/저축/연금/비상금/용돈 비율 제안이 계산됩니다. 실제 소득/예산 관리는 **처음 등록한 2명(보통 부모)** 으로 제한 — 3번째 이후 가구원[아이 등]은 소비 태깅에만 쓰이고 소득 입력 대상에서 제외)

1. 이제 가구원별 월 평균 소득을 입력해주세요.
2. [가구원1]님의 월 평균 소득은 얼마인가요?
3. [가구원2]님의 월 평균 소득은 얼마인가요? (소득관리 대상은 처음 2명까지만 — 3번째 이후 가구원은 건너뜀)
4. 우리 가족의 월 평균 소득은 총 [합계]으로 계산됐어요!

## 세팅 시작 — 고정비 / 주거

1. 먼저 고정비용부터 세팅할거예요! 주거비부터 세팅해 볼까요?
2. 현재 대출이 있으신가요? 대출금을 입력하세요.
3. 월에 주거 관리비는 얼마나 나오나요?
4. 월에 통신비는 얼마나 나오나요? (이용 중인 통신사 앱에서 월 통신비를 조회해 보세요.)
5. 보유하신 주택이 있다면, 재산세는 얼마나 내시나요? 매년 내야할 금액을 달 마다 모으기로 해요! (재산세는 매년 7월과 9월 두번에 나눠서 납부해야 합니다. 재산세는 지방세로 지방세 맞춤 플랫폼인 위택스에서 1년 납부 내역을 확인할 수 있어요!)
6. 이제 주거비가 세팅됐어요!

## 세팅 시작 — 고정비 / 보험

1. 이제 고정비 중 보험비예요! 보험비는 나중에 세부항목을 입력해도 됩니다. 편하게 월 평균 비용만 입력해 주세요!
2. 이제 보험비가 세팅됐어요!

## 희망고문

> (계산 로직: 아래 생활20%·저축20%·노후자금10%·비상금5%·용돈5% = 소득의 60%는, "고정비가 소득의 40%"인 표준 케이스를 가정한 화면 표기용 숫자. 실제 계산은 **여유예산(=총소득−고정비) 안에서 4:4:2:1:1 상대 비율**로 배분 — 고정비가 40%보다 크든 작든 여유예산 100%가 항상 정확히 채워지고 마이너스 예산이 나오지 않음. 표준 케이스[고정비=40%]에서는 화면 숫자와 실제 배분이 정확히 일치)

고정비용이 다 세팅됐어요!
이제부터는 생활비, 저축, 노후자금, 비상금, 용돈을 설계할거예요!
이 세팅으로 미래의 내가 행복해집니다. 지금의 나 자신을 매우 칭찬하게 될거예요!

## 생활비 세팅

월 평균 생활비를 얼마로 세팅하실 계획인가요? 버짓앱에서는 여유예산(소득−고정비)의 1/3(표준 케이스 기준 소득의 20%)을 제안 드리고 있어요!

## 저축 세팅

저축을 얼마를 목표로 하고 계신가요? 버짓앱에서는 여유예산의 1/3(표준 케이스 기준 소득의 20%)을 제안드리고 있어요!

## 노후자금 세팅

> (화면 표기는 "노후자금"이 사용자 친화적이라 채택. 단 스프레드시트 `2026`/`2025` 탭엔 이미 "연금/IRP 지원", "연금/IRP 윤혜" 행 이름이 있어서, 앱→시트 월간 싱크 시 내부 필드는 시트 쪽 "연금/IRP" 그대로 매핑 — 시트 구조 변경 없음)

노후자금은 얼마를 목표로 하고 계신가요? 버짓앱에서는 여유예산의 1/6(표준 케이스 기준 소득의 10%)을 제안드리고 있어요!

## 비상금 세팅

세팅한 자금들의 운용을 제대로 유지하려면, 변수가 적어야 해요.
비상금은 그런 의미에서 매우 중요한 항목입니다.
병원비, 차량관리(수리·정비), 여행비, 가족 경조사, 지인 경조사 등을 비상금에서 관리해요! 그럼 비상금을 얼마로 세팅하시겠어요? 버짓앱은 여유예산의 1/12(표준 케이스 기준 소득의 5%)로 제안드리고 있습니다.

> (참고: 위 5개 카테고리는 기존 스프레드시트 `비상금내역` 탭 분류와 동일하게 맞춤)

## 용돈 세팅

작고 소중한 내 용돈, 마지막에 남은 비율로 버짓앱이 그냥 세팅해 드려요. 버짓앱은 여유예산의 1/12(표준 케이스 기준 소득의 5%)로 잡았습니다. 너무 작아 당황하셨나요? 여행도 못가고, 연애도 못하고, 친구도 못만날 것 같나요? 내 드림카도 평생 구경 못할까 겁나시나요?
버짓앱이 철저하게 다 준비했습니다. 용돈은 거들 뿐!

용돈 총액은 소득관리 대상 2명(예: 지원·윤혜)에게 **소득 비례로 기본 배분**돼요. (예: 지원 소득이 전체의 51%면 용돈도 51:49로 자동 배분) 물론 직접 비율을 조정하실 수 있어요!
