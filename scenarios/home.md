# 사용 시나리오 — 초기화면 (홈)

> (Claude 초안 — 온보딩에서 입력받은 데이터를 읽어 매번 앱을 열 때 보여주는 상시 대시보드. 온보딩과 달리 대화형이 아니라 화면 구성이므로, 영역(섹션) 단위로 기술)

온보딩 완료 직후 & 이후 앱을 열 때마다 진입하는 화면.

## 1. 상단 요약

- 이번 달 이름 + 오늘 날짜, 월말까지 D-[남은 일수]
- 이번 달 총소득 / 고정비(주거+보험) 합계 / 여유예산 잔액(=여유예산−이번 달 누적 지출)
- 고정비는 **변동사항이 없으면 매달 자동으로 동일 금액 차감** (온보딩에서 입력한 값 유지). 통신비처럼 달마다 금액이 바뀌면 설정에서 직접 수정
- 잔액이 마이너스면 빨간색 강조 + "이번 달 예산을 [X]원 초과했어요" 배너

## 2. 카테고리별 진행 현황 (프로그레스 바 5개)

온보딩에서 설정한 목표 대비 이번 달 진행률을 각각 표시:

| 카테고리 | 표시 |
|---|---|
| 생활비 | 진행률 바 (이번 달 지출 / 목표) |
| 저축 | 진행률 바 + **"이번 달 저축 이체 완료" 체크박스** |
| 노후자금 | 진행률 바 + **"이번 달 노후자금 이체 완료" 체크박스** |
| 비상금 | 다른 4개와 다른 3단 카드 구성 (아래 별도 설명) |
| 용돈 | 지원/윤혜 각자 막대 (소득비례 배분값 대비 개인 소비) |

> (TODO 후보: 저축/노후자금은 "쓰는" 카테고리가 아니라 "모으는" 카테고리라 생활비/용돈과 진행바 방향(꽉 찰수록 좋음 vs 꽉 차면 위험)이 반대. UI에서 색상/아이콘으로 구분 필요 — Figma 단계에서 확정)

### 저축/노후자금 "이체 완료" 체크박스

저축·노후자금은 "여유예산에서 안 쓰면 자동으로 저축된 것"으로 간주하지 않음 — 실제로 다른 계좌(적금·연금저축·IRP 등)로 옮겼는지를 매달 가벼운 체크박스로 직접 확인받음.

- 진행률 바는 목표 금액 대비 참고용으로 계속 표시
- 월말이 가까운데 미체크 상태면 "이번 달 저축 아직 이체 안 하셨어요!" 알림
- 체크 안 해도 앱 사용을 막지는 않음(강제 아님), 다만 리포트에서 "이체 완료율"을 별도로 보여줘 실제 저축 습관을 추적

### 비상금 카드 (3단 구성)

비상금은 다른 4개와 달리 "적립"뿐 아니라 병원비·차량수리 등 실제 "인출"도 일어나는 유일한 카테고리라 진행바 하나로는 부족함. 다음 3단으로 구성:

1. **누적 잔액 (메인, 크게)** — 예: "비상금 잔액 ₩1,234,000"
2. **이번 달 적립 진행바 (보조, 작게)** — 예: "이번 달 목표 ₩150,000 중 ₩100,000 적립"
3. **이번 달 인출 내역 (있을 때만 표시)** — 예: "이번 달 사용 ₩50,000 (차량 수리)"

## 3. 지출 빠르게 입력 (핵심 액션)

- 화면 우측 하단 고정 버튼(FAB): "+ 지출 입력"
- 탭하면 최소 입력(금액 → 카테고리 → 항목명, 날짜는 오늘 기본값)으로 3탭 이내 입력 완료를 목표
- 입력한 가구원(지원/윤혜/누구 소비인지)은 로그인 계정 기준 자동 태깅, 필요하면 다른 가구원으로 변경 가능 (예: 윤혜가 진우 물건을 사면서 "진우" 태그로 남기는 경우)

## 4. 최근 지출 내역

- 최근 5~10건 리스트: 날짜 · 항목 · 금액 · 카테고리 뱃지 · 가구원 뱃지
- 항목 탭하면 수정/삭제
- "전체 내역 보기" → 리포트 화면으로 이동

## 5. 가구원 필터

- 상단 탭 또는 드롭다운: [전체] [지원] [윤혜] [아이]
- 선택 시 2번(진행 현황)·4번(최근 내역) 둘 다 해당 가구원 태그로 필터링

## 6. 하단 네비게이션

- 홈 / 지출입력 / 리포트(분석.그래프 대응: 월별 추이·카테고리 비율) / 설정(가구원·목표 재설정)

## 7. 빈 상태 (Empty State)

- 이번 달 첫 지출 입력 전: "아직 이번 달 지출이 없어요. 첫 지출을 입력해볼까요?" + FAB 강조
