# 사용 시나리오 — 지출 입력

> (Claude 초안)

## 진입 경로

- 홈 화면 FAB("+ 지출 입력")
- 홈 "최근 지출 내역"에서 항목 탭 → 같은 화면이 값 프리필된 수정 모드로 열림

## 0. 지출 모드 선택 (일반 vs 비상금)

기존 스프레드시트가 `2026 소비내역`(일반 소비, 8개 카테고리)과 `비상금내역`(별도 5개 카테고리)을 처음부터 분리된 탭으로 관리하고 있어서, 앱도 같은 구조를 따름:

- **[일반 지출]** (기본) — 8개 카테고리 그리드가 기본으로 열림
- **[비상금 지출]** — 카테고리 그리드 맨 끝에 "🚨 비상금에서 지출" 칩을 하나 추가. 탭하면 카테고리 목록이 5개(병원비/차량관리/여행비/가족경조사/지인경조사)로 전환되고, 저장 시 비상금 잔액에서 차감

> (결정: 비상금 지출 빈도가 낮으므로 상단 세그먼트 토글 대신 칩 하나로 축소 — 압도적으로 많이 쓰는 일반 지출 화면을 더 깔끔하게 유지)

## 1. 입력 필드 순서 및 기본값

1. **금액** (필수) — 화면 진입 시 숫자 키패드 자동 포커스
2. **카테고리** (필수, 단일 선택 칩/그리드) — 모드에 따라 8개 또는 5개
3. **항목명** (필수, 텍스트)
4. **날짜** (기본값: 오늘) — 탭하면 캘린더로 변경
5. **가구원 태그** (기본값: 로그인 계정 본인) — 탭하면 지원/윤혜/아이 중 변경 가능
   - 카테고리("자녀" 등, 무엇을 위한 지출인지)와 가구원 태그(누구 소비로 잡을지)는 서로 다른 축 — 예: 윤혜가 진우 기저귀를 사면 카테고리="자녀", 가구원 태그="아이"
6. **메모** (선택) — 기본 접힘, 탭하면 펼쳐짐

## 2. 빠른 입력 최적화

- 카테고리 선택 전에 **최근/자주 쓴 항목 3~5개를 칩으로 노출** (예: "진우 유산균", "쿠팡 장", "톨비") — 실제 데이터 기준 매달 반복되는 정기 지출이 많음(유산균 등)
- 칩 탭 → 항목명·카테고리·가구원 태그 자동 채움, 금액만 입력하면 저장 가능
- 목표: 반복 지출은 **칩 선택 + 금액 입력 2탭**으로 완료

## 3. 저장 및 피드백

- 저장 버튼 탭 → 토스트 "저장됐어요" + 홈으로 복귀
- 홈의 해당 카테고리 진행바가 즉시 갱신되어 보임
- 이번 달 해당 카테고리 목표를 초과하게 되는 입력이면, 저장 전에 "이번 지출로 [카테고리] 목표를 초과해요 (₩X 초과)" 확인 배너 — 저장 자체는 막지 않음(경고만)
- **경고 적용 범위**: 소비형 카테고리(생활비/용돈/비상금)에만 적용. 저축·노후자금은 "모으는" 카테고리라 계획보다 많이 이체해도 초과가 아니라 오히려 좋은 상황이므로 경고 없음

## 4. 수정 · 삭제

- 홈/리포트에서 기존 항목 탭 → 값이 채워진 채로 이 화면이 열림
- 화면 하단 "삭제" — 확인 다이얼로그 후 삭제
