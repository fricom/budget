# 사용 시나리오 — 리포트

> (Claude 초안 — 홈 화면 하단 네비 "리포트" 진입. 스프레드시트 `분석.그래프` 탭(월별 총 지출, 카테고리별 합계 차트 2개)을 앱 화면으로 대응시킴)

## 1. 상단 기간 선택

- 기본값: 이번 달
- 탭하면 [이번 달] [최근 3개월] [올해 전체] [월 직접 선택] 중 변경 가능
- 기간에 따라 아래 2·3·5번 섹션이 모두 다시 계산됨

## 2. 월별 지출 추이 (분석.그래프 "월별 지출 추이" 대응)

- 막대/선 그래프: 월별 총 지출 vs 월 예산선(생활비 목표 기준)
- 예산 초과 월은 막대 색을 경고색으로 표시
- 아직 지출이 없는 미래 달(예: 10~12월)은 회색 처리, "아직 데이터 없음"
- 그래프의 특정 월 탭 → 해당 월로 기간 필터 전환(1번 섹션과 연동)

## 3. 카테고리별 비율 (분석.그래프 "카테고리별 월별 지출" 대응)

- 도넛/파이 차트: 선택 기간 내 8개 카테고리(생활/자녀/외식/교통/여가/쇼핑/의료/기타) 합계 비율
- 범례 항목 탭 → 4번(카테고리 상세)으로 drill-down
- 비상금 5개 카테고리(병원비/차량관리/여행비/가족경조사/지인경조사)는 이 차트에 섞지 않고 6번에서 별도 표시 (일반 소비내역과 비상금내역이 스프레드시트에서도 분리 탭으로 관리되는 것과 동일한 원칙)

## 4. 카테고리 상세 (drill-down, 일반 8개 카테고리 전용)

- 3번에서 카테고리 탭 시 진입: 해당 카테고리의 기간 내 전체 지출 리스트(날짜·항목·금액·가구원 태그)
- 상단에 해당 카테고리 합계 + 목표 대비 진행률(목표가 있는 카테고리만: 생활비)
- 비상금 관련 내역은 이 화면에 나타나지 않음 — 6번 비상금 리포트 섹션에서만 확인 가능 (스프레드시트가 `2026 소비내역`/`비상금내역` 두 탭을 계속 분리해온 원칙을 유지)

## 5. 가구원별 비교

- 홈 화면과 동일한 [전체]/[지원]/[윤혜]/[아이] 필터
- 선택 시 2·3번 차트가 해당 가구원 태그 기준으로 재계산
- 용돈 카테고리는 가구원별 목표 대비 소진율을 막대로 비교 표시 (지원 vs 윤혜)

## 6. 비상금 리포트 (별도 섹션)

- 누적 잔액 추이 그래프(월별 적립/인출로 잔액이 어떻게 움직였는지)
- 인출 내역 리스트: 5개 카테고리별 합계 + 개별 건 리스트
- 홈 화면 비상금 카드(3단 구성)의 확장판

## 7. 저축·노후자금 이체 완료율

- 홈 화면 체크박스(이번 달 이체 완료)의 누적 통계
- "최근 6개월 중 저축 이체 완료 O회 / 노후자금 이체 완료 O회" 같은 형태로 실제 습관 추적
- 목표 금액 대비 실제 이체 금액 추이도 함께 표시(체크만 하고 금액이 다른 경우 발견 가능하도록)

## 8. 스프레드시트 동기화

- 아키텍처상 앱이 원본 DB, 스프레드시트는 연말 리포트 뷰 — B-1(월간 실적 싱크)이 백그라운드에서 자동으로 처리, 리포트 화면에는 내보내기 버튼을 노출하지 않음
- 동기화 상태 확인/수동 재시도는 설정 화면(`settings.md` 6번 "데이터·동기화")에서만 제공
